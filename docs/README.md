# OctoAcme Project Management Docs

## Overview

OctoAcme follows a structured, iterative project management approach centered on customer value, clear ownership, and data-informed decisions. Our processes balance flexibility with consistency, enabling teams to deliver reliably while adapting to change.

## Core Principles

- **Customer-first**: Prioritize customer value and usability
- **Iterative delivery**: Deliver small, testable increments
- **Clear ownership**: Each project has named owners (PM, Product Manager)
- **Data-informed**: Measure impact and iterate based on evidence
- **Psychological safety**: Encourage feedback and continuous learning

## Communication Cadence

OctoAcme projects follow a consistent rhythm of engagement:

- **Daily standups** (15 min) — Focus on progress, blockers, dependencies
- **Weekly syncs** — PM + Product Manager alignment
- **Twice-weekly standups** — Delivery team coordination
- **Monthly stakeholder updates** — High-level status and roadmap
- **Regular demos** — End of sprint or milestone review
- **Retrospectives** — After sprint, release, or important milestone

## Key Artifacts by Phase

| Phase | Key Artifacts |
|-------|--------------|
| **Initiation** | Project One-pager, Stakeholder list, Initial timeline |
| **Planning** | Prioritized backlog, Release plan, Definition of Done, Risk register |
| **Execution** | Sprint backlog, PRs with acceptance criteria, Test results, Risk updates |
| **Release** | Release notes, Deployment checklist, Smoke tests, Rollback plan |
| **Retrospective** | Retrospective notes, Action items, Lessons learned |
